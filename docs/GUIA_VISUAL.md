# Guía visual: acceso al sistema de diseño

La autoridad visual de la web pública es [design.md](design.md), extraída del [sitio Base44](https://preview--turu-guia-local.base44.app/). Este archivo conserva el enlace de entrada; no mantiene tokens ni reglas independientes.

Consulta los [tokens](design-ref/design-tokens.json), el [inventario de componentes](design-ref/component-inventory.md), las [capturas con procedencia](design-ref/screenshots/manifest.json) y la [guía de implementación y comparación](design-ref/implementation-guide.md).

La especificación maestra conserva la autoridad funcional. Filament mantiene su sistema administrativo. El futuro panel de usuario heredará el sistema público cuando se apruebe su alcance, sin habilitar cuentas en el lanzamiento actual.

Los valores y las capturas de la guía anterior se conservan en el historial Git y en [referencias/capturas](referencias/capturas/26-mapa-de-pantallas.jpg). Son antecedentes visuales, no evidencia de contenido ni requisitos funcionales. Las diferencias frente a Base44 están registradas en el manual.

La [puerta transversal de diseño](MEMORY.md#puerta-transversal-de-diseno-antes-de-vs04) está integrada: el manual y la alineación de las superficies públicas se fusionaron en PR #6 y PR #8. VS04 se completó e integró mediante [PR #11](https://github.com/luisfridev/tugurulocal/pull/11). Cuatro comprobaciones asistidas de accesibilidad siguen aplazadas a VS15 y no se registran como aprobadas; la integración no acredita producción.
