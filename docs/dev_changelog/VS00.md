# VS00 — Base ejecutable

**Fecha:** 21 de octubre de 2026. **Rama:** `codex/vs00-base-ejecutable`. **Estado:** completada y comprobada localmente. **Alcance:** preparación técnica; la guía pública todavía no está implementada ni publicada.

## Qué se hizo

VS00 convirtió el paquete de documentación en una aplicación Laravel que puede instalarse, migrarse, probarse y compilarse. El proyecto se creó desde cero. Se generó Laravel en una carpeta temporal y se integró aquí conservando los documentos y las 26 capturas de referencia. No se importaron código, datos, negocios, rutas ni redirecciones del sitio anterior.

### Aplicación y dependencias

- Se añadió la estructura habitual de Laravel: `app/`, `bootstrap/`, `config/`, `database/`, `public/`, `resources/`, `routes/`, `storage/` y `tests/`.
- Se instalaron Laravel 13, Livewire 4, Filament 5 y Media Library con su integración para Filament. La interfaz usa Tailwind 4 y DaisyUI 5. PHPUnit permite probar el comportamiento; Pint revisa el formato del PHP. Boost y Debugbar son dependencias de desarrollo, y Debugbar permanece apagada por defecto.
- `composer.lock` y `package-lock.json` fijan las versiones resueltas. Las versiones comprobadas incluyen PHP 8.4.25, MySQL 8.4.5, Laravel 13.38.0, Livewire 4.4.8, Filament 5.10.3, Media Library 11.23.10, Tailwind 4.3.3, DaisyUI 5.7.50 y Vite 8.3.5. El detalle se mantiene en [TECH-STACK.md](../TECH-STACK.md).
- Las tipografías se sirven desde paquetes locales de Fontsource, por lo que la compilación no depende de descargar fuentes externas.

### Base de datos, configuración y acceso

- Se preparó `.env.example` para MySQL y `phpunit.xml` para usar una base de pruebas separada. La comprobación local utilizó `tugurulocal_nuevo_dev` y `tugurulocal_nuevo_test` en una instancia MySQL temporal. Las migraciones crean las tablas iniciales de Laravel y la tabla de Media Library; todavía no hay tablas ni datos editoriales del negocio.
- La aplicación guarda instantes en UTC y define `America/Cancun` como zona horaria de presentación para el producto. Se configuró la base de la interfaz en español.
- Filament quedó instalado en `/admin`. Los usuarios nuevos tienen `is_super_admin=false` y el modelo `User` les impide entrar al panel. La creación segura del primer administrador, el segundo factor, las políticas y la auditoría pertenecen a VS01; aún no se ha habilitado la operación administrativa real.
- Se excluyeron de Git archivos de entorno y bases locales, dependencias, compilados y otros archivos generados. `.env` contiene solo configuración local y no forma parte del repositorio. No se crearon cuentas ni negocios de ejemplo para producción.

### Pantalla temporal y límites públicos

- La ruta `/` muestra una pantalla temporal en español, adaptable a móvil, tableta y escritorio, con los primeros estilos del sistema visual. Se retiró el favicon genérico mientras llega el logotipo oficial.
- La pantalla lleva `noindex,nofollow` y `robots.txt` bloquea el rastreo durante esta etapa. No enlaza módulos aún inexistentes. `/register` y `/premium` responden 404; no hay cuentas públicas ni página comercial visible.

### Documentación y forma de trabajo

- Se actualizaron [README.md](../../README.md), [AGENTS.md](../../AGENTS.md), [DISENO_TECNICO.md](../DISENO_TECNICO.md), [TECH-STACK.md](../TECH-STACK.md), [PLAN_IMPLEMENTACION.md](../PLAN_IMPLEMENTACION.md) y [MEMORY.md](../MEMORY.md) para distinguir la base local terminada de los módulos y el lanzamiento pendientes.
